## 安全边界

开发模式的后端没有账户系统或访问鉴权，只用于本机或受信任网络，不要直接暴露到公网。桌面版由 App 自己启动后端，带一个随机端口和一次性访问令牌，本机别的进程打不开它；但如果同一用户能读 `data/` 目录，仍然能看到数据库里的明文 key。对话以明文存入本地 SQLite。指定模型地址使用 HTTP 时，请求正文和凭据没有传输加密。

工具包让模型能上网、记事、算数、读写文件，配置都在 `backend/.env.example` 里逐项注明。

- 搜索会把查询词发给选中的第三方搜索服务（Parallel、Exa、Tavily、Brave 或 DuckDuckGo），这些请求离开本机。
- `WORKSPACE_DIR` 是工作文件夹：相对路径都落在这里。范围外的位置要你同意（或选了完全权限）才碰得到，Cubes 自己的数据目录永远碰不到。
- 运行代码不是沙箱：子进程以当前用户身份运行，只是拿不到模型和搜索密钥，最长 60 秒、输出有上限。自动审批和完全权限下它不再先问你，有敏感数据的账号上请留在手动审批。
- 「本机」直接操作后端所在的电脑。桌面版就是这台 Mac：命令、截屏和键鼠都打在这台机器上，第一次使用会先问你允许；网页用的是 Cubes 自己的 Chrome 窗口和独立配置，不是用户平时的浏览器。云端电脑才是连上来的另一台机器。截图、命令输出和网页内容会存进本地数据库，并发给当前模型服务。
